Mini Coding Agent 项目说明

一、Git 仓库地址
https://github.com/CRYEAH6/mini-coding-agent

二、项目简介
本项目是一个编程Agent，可以帮助用户在本地完成日常的编程任务。项目采用终端CLI形式。
用户提出开发需求，系统借助大语言模型理解任务并决定工具调用，在指定工作区内完成文件读取、代码修改、命令执行和结果验证。
大语言模型负责理解用户需求、决定下一步操作并生成回复；本地程序负责维护对话上下文、解析工具调用、安全执行文件与命令操作，再将执行结果反馈给模型，循环工作直至任务完成或满足终止条件。
工作流程：接收任务 -> 模型决策 -> 本地执行 -> 结果反馈

三、如何运行
运行环境：macOS、Python 3.9 及以上、uv，以及支持OpenAI兼容接口和工具调用的模型API。

1. 克隆并进入项目：
git clone https://github.com/CRYEAH6/mini-coding-agent.git
cd mini-coding-agent

2. 安装依赖：
uv sync --extra dev

3. 配置环境变量：
cp .env.example .env
在 .env 中填写LLM_API_KEY、LLM_MODEL和LLM_BASE_URL，请勿公开或提交真实密钥。

4. 启动 Agent：
uv run mini-agent --workspace /目标项目的绝对路径

启动后在“你>”提示符后输入任务即可。同一对话中可以继续追加或修改需求；输入 /help 查看命令，输入 /exit 退出。

四、特色功能
1. 支持连续对话、流式回复、多会话保存、恢复与切换。
2. 提供文件浏览、读取、写入、局部替换、命令执行及Git状态、差异和检查点等本地工具。
3. 具备完整的工具调用循环，会保存模型决策、工具参数和真实执行结果，支持工具调用失败后的自动重试与策略调整。
4. 上下文超限后自动进行上下文压缩，调用模型生成语义摘要，同时保留近期任务和完整工具调用关系。
5. 支持工作区级长期记忆，可记录并检索用户偏好和项目约定。
6. 具有路径越界防护、危险命令确认、超时、最大循环次数、重复调用和连续失败检测等安全机制。
